## 复现

Node.js 22或更新的受支持版本；本地PowerShell：

```powershell
npm ci
npm run build
npm test
npm run test:mcp
$env:PLAYWRIGHT_CHANNEL = "chrome"
npm run test:e2e
Remove-Item Env:PLAYWRIGHT_CHANNEL
```

浏览器测试使用已有Chrome的独立测试实例，不读取个人浏览器资料。采用默认Chromium时需先按Playwright官方方法安装；本轮没有验证该下载路径。测试环境需允许构建和浏览器子进程。
